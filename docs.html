WaifuEngine Dokümantasyonu

Tarayıcıda çalışan 3D anime karakter motoru. Ziyaretçi hiçbir program kurmaz; model ve motor tek bir script etiketiyle yüklenir. 40 hazır karakter, ince gömme boyutu, ifadeler, dudak senkronu, fizik ve fare takibi kutudan çıkar.

Hızlı başlangıç

Script'i sayfaya ekleyin, ardından <waifu-stage> etiketini yerleştirin. Model yolu verilmezse karakterin varsayılan VRM'i kullanılır. 

<script src="https://cdn.example.com/embed/waifu-embed.js" defer></script>

<waifu-stage
  preset="mia"
  asset-base="https://cdn.example.com"
  background="transparent"
  quality="auto"
  style="width:100%;height:640px"
></waifu-stage>

JavaScript API

Etiket hazır olduğunda ready olayı yayınlanır. Motoru getEngine() ile alabilirsiniz. 

const stage = document.querySelector('waifu-stage');
stage.addEventListener('ready', () => {
  const engine = stage.getEngine();

  engine.say('Merhaba, ben Mia!', { emotion: 'happy', gesture: 'wave' });
  engine.play('sit');          // wave · laugh · cry · shy · think · sit · jump · yawn · stretch
  engine.setEmotion('shy');
  engine.lookAt(0.6, -0.2);    // -1..1 ekran koordinatı
  engine.setCharacter({ hair: { color: '#f0a6c8', length: 1.08 } });
});

Olaylar: ready, loadprogress, statechange, emotionchange, speechstart, speechend, viseme, poke, error, contextlost.

Karakter JSON'u

Her şey tek bir şema ile ifade edilir: cinsiyet, görünüm, vücut oranları, yüz, saç (renk, uzunluk, hacim, fizik), kıyafet renkleri ve aksesuar görünürlüğü, ten tonu ve mizaç. Studio'daki tüm değişiklikler anında uygulanır ve tarayıcıda saklanır.

Performans

  • Modeller HD authored dokularla gelir; her VRM yaklaşık 5,6–9,3 MB (2K doku + normal harita).
  • 13 farklı temel model (10 kadın / 3 erkek); yüzlerce kombinasyon roster ile gelir.
  • Yalnızca seçilen karakterin modeli indirilir; diğerleri tembel yüklenir.
  • Masaüstünde 60 FPS, lite modunda 30 FPS hedeflenir.
  • Sayfa görünmezken render döngüsü durur; pixel ratio otomatik sınırlandırılır.
