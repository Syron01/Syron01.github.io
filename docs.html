Dokümantasyon

Tarayıcıda çalışan 3D anime karakter motoru. Ziyaretçi hiçbir program kurmaz; model ve motor tek bir script etiketiyle yüklenir. 40 hazır karakter, ifadeler, dudak senkronu, fizik ve fare takibi kutudan çıkar.

Hızlı başlangıç

Script'i sayfaya ekleyin, ardından <waifu-stage> etiketini yerleştirin. Model yolu verilmezse karakterin varsayılan VRM'i kullanılır. 

<script src="https://cdn.example.com/embed/waifu-embed.js" defer></script>

<waifu-stage
  preset="mia"
  asset-base="https://cdn.example.com"
  background="transparent"
  quality="auto"
  style="width:100%;height:640px"
></waifu-stage>

JavaScript API

Etiket hazır olduğunda ready olayı yayınlanır. Motoru getEngine() ile alabilirsiniz. 

const stage = document.querySelector('waifu-stage');
stage.addEventListener('ready', () => {
  const engine = stage.getEngine();

  engine.say('Merhaba, ben Mia!', { emotion: 'happy', gesture: 'wave' });
  engine.play('sit');
  engine.setEmotion('shy');
  engine.lookAt(0.6, -0.2);
  engine.setShader(false);
  engine.resetTransform();
  engine.setCharacter({ hair: { color: '#f0a6c8', length: 1.08 } });
});

Olaylar: ready, loadprogress, statechange, emotionchange, speechstart, speechend, viseme, poke, error, contextlost.

Karakter JSON'u

Cinsiyet, görünüm, vücut oranları, yüz, saç, kıyafet, ten tonu ve mizaç tek şemada tanımlanır. Studio'daki tüm değişiklikler anında uygulanır ve tarayıcıda saklanır.

Performans

  • Her VRM yaklaşık 5,6–9,3 MB; authored 2K doku ve normal harita.
  • 13 temel model (10 kadın / 3 erkek), 40 karakter.
  • Yalnızca seçilen model indirilir.
  • Masaüstünde 60 FPS, lite modunda 30 FPS.
  • Sayfa görünmezken render durur; pixel ratio sınırlandırılır.
